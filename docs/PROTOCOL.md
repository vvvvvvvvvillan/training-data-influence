# 实验协议与数据来源

## 数据隔离

CIFAR-10官方训练集固定分层划分：D_train10000、V_attr2000、V_tune2000、预留未使用V_effect2000、独立生成器G_noise10000，剩余24000不用。划分seed31415；官方测试10000张仅作最终评价。模型seed200–204。各噪声类型中20%错误集合嵌套于40%，已错样本目标标签复用。

随机错标将选中样本均匀改成其他九类；类别依赖错标为(y+1)%10；实例依赖错标由在独立G_noise上训练的seed9000模型产生，选择权重0.05+1−q(true|x)，其他类别按q(c|x)+1e−6采样。真实标签不用于可疑度评分，仅用于造噪、评价和oracle审核。

## 模型与清理

全网络ResNet-18训练；分类头512维特征加bias，共5130参数。SGD momentum0.9、weight decay0.0005（含bias）、batch128、7900步；395步warmup从0.01到0.1，之后cosine至0。随机裁剪padding4、水平翻转，输入每通道(x/255−0.5)/0.5。FP32禁TF32；评分确定性输入、BatchNorm eval；固定最终checkpoint。干净校准seed100/101通过并冻结100epochs/lr0.1。

每种方法选前1000个样本。Correct恢复真实标签，Remove删样本；两者都从相同seed完整重训、保持7900步。删除后样本遍历次数更多，训练更新次数相同不表示处理图片次数完全相同。

## 四种方法

- Random：固定种子的随机排序。
- Loss：最终模型对含噪标签的交叉熵。与当前标签置信度的反向排序等价。
- IF：S_i=−g_iᵀv，v=(H+λI)⁻¹g_val。H为冻结特征下头部的平均训练交叉熵Hessian加L2，λ默认0.01；CG float64、rtol1e−6、最多500迭代，数值失败才回退0.1/1。正高分表示增权预计损害干净验证表现。不是全网络精确IF。
- TracInCP-self-last-layer：S_i=Σ_k η_k||∇_head loss_i(w_k)||²，checkpoint为epoch10,20,…,90，η为对应实际训练步学习率；梯度含bias、不含L2梯度。每个checkpoint使用自身encoder特征。该方法不使用V_attr。原训练没有保留全部历史权重，因此按相同协议重放；30组最终参数与原模型的最大差均为0。

## 指标与审计

AP是sklearn.average_precision_score，正类为实际被改错的样本；P@10%=命中数/1000，R@10%=命中数/全部错标数。AUROC另行报告。所有均值与SD基于5个种子；提升为清理后accuracy减同组基础accuracy。

源实验和补充实验完成后已经核验矩阵齐全、分数有效、IF求解收敛、TracIn重放一致、选样及AP重算一致。此仓库脚本进一步验证最终四方法矩阵、指标范围和提升/命中算术一致性。源表AP的逐样本重算依赖仍留存于服务器的分数和mask，此仓库不含这些大体积源产物。

## 研究边界

这里展示的四方法结果是完整实验后选定的最终展示范围，不修改原始数值；原实验记录保存在仓库外。只做描述性结论，不能把报告范围整理解释为事先指定的新主要终点。IF额外消耗干净标签，TracIn额外利用训练历史；缺少相同信息预算的对照。
